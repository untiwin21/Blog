## 핵심 개념

함수 $f(n)$이 $O(g(n))$ 이라는 것은, 충분히 큰 $n$에서 $f$가 $g$의 상수배 이하라는 뜻이다.

$$
f(n) = O(g(n)) \iff \exists\, c > 0,\ n_0 \ \text{s.t.}\ \forall n \ge n_0,\ 0 \le f(n) \le c\,g(n)
$$

## 유도: 이진 탐색

탐색 구간이 매 단계 절반으로 줄어드므로 $T(n) = T(n/2) + O(1)$ 이고, 이를 풀면 $T(n) = O(\log n)$ 이다.

## 예시

```ts
function binarySearch(arr: number[], target: number): number {
  let lo = 0, hi = arr.length - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) lo = mid + 1;
    else hi = mid - 1;
  }
  return -1;
}
```
